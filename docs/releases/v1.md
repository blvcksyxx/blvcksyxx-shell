# blvcksyxx shell v1

**blvcksyxx shell v1** is a Hyprland and niri desktop with a Material 3 settings app,
bar and dynamic island, launcher, desktop widgets, dock, lock screen and security tools.

The internal `VERSION` is `1`, the release is named `v1`, and the tag is `v1`.

## Highlights

- **Settings app** (`SUPER + U`): every option in one Material 3 app, with search, tabs,
  live previews and 20 languages.
- **Bar and dynamic island**: a clock in the middle that grows into music, volume,
  workspaces, notifications, weather and today; six bar styles, auto-hide, a tray,
  workspace dots or Pac-Man, and a Waybar fallback.
- **Desktop**: a launcher with five themes, a dock, 24 desktop widgets, a wallpaper picker
  with live colors, a lock screen and a hot corner.
- **Window managers**: Hyprland and niri, with the same bar, widgets, menus and Settings.
  Choose one or both at install time.
- **Extra desktop tools**: Infinite Desktop (an endless canvas for floating windows),
  keybind editor, gaming mode, performance switches, screen recording, screenshots,
  media and lyrics, weather, updates and a welcome window.
- **Security**: ClamAV quick and full scans, a quarantine, a system check, scheduled scans,
  shell-file integrity checks and optional kernel hardening.
- **Installers** for Arch Linux, CachyOS, EndeavourOS, Garuda, Fedora, Nobara and NixOS,
  with backups and a one-command restore.

## Install

```bash
sudo pacman -S --needed git base-devel   # Arch / CachyOS / EndeavourOS / Garuda
git clone https://github.com/blvcksyxx/blvcksyxx-shell
cd blvcksyxx-shell
./install.sh
```

Fedora / Nobara:

```bash
sudo dnf install -y git
git clone https://github.com/blvcksyxx/blvcksyxx-shell
cd blvcksyxx-shell
./install.sh
```

NixOS: add `nix/module.nix` to `configuration.nix`, run `nixos-rebuild switch`, then
`./install.sh` from the cloned repository.

The installer asks which window manager you want, installs the packages, copies the
configs and saves every replaced file in
`~/.config/blvcksyxx-shell-backup-<time>/`. Use `./install.sh --restore` to put the last
backup back.

## Privacy

The repository contains no personal data, accounts, tokens, private keys, machine names
or hardware serial numbers. Wallpapers and previews are included with the project.
