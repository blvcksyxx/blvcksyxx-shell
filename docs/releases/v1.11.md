# blvcksyxx shell v1.11

v1.11 brings the shell up to date with a large batch of upstream work: a new screenshot
tool, Infinite Desktop with a moving wallpaper, the Material 3 lock screen, clipboard
history, the wallpaper carousel, window rules, the shell's own login screen and much more.
The blvcksyxx identity and the shell's security hardening stay.

## Highlights

- **Screenshots** (`Print`, `SUPER + SHIFT + S`): the screen freezes and a Material 3
  toolbar offers Region, Window and Screen. Region can be dragged, moved and resized, shows
  its real pixel size and a loupe; Window is outlined with the app name. Save to
  `Pictures/Screenshots` and copy, copy only, open in satty or swappy, or cancel with `Esc`.
- **Infinite Desktop**: the wallpaper travels with the canvas and the bar and dock step
  aside while you pan. The wallpaper zoom is adjustable from 1.05x to 1.5x, and the motion
  is live while `SUPER + ALT` and the mouse are held, and smooth with the keys, the wheel
  and `SUPER + CTRL` + arrows. Fixes cover NVIDIA, Steam notification toasts, a second
  daemon and the input group working without logging out.
- **Lock screen**: a new Material 3 style (Cards) next to Classic, a real preview in
  Settings, a 30-second test, clock fonts that install themselves, music, keyboard layout
  and power buttons. hyprlock stays only as a fallback.
- **Clipboard history** (`SUPER + V`): texts and pictures, search, pinning, paste at once
  and a configurable history size. `cliphist` and `wtype` are installed by the installer.
- **Wallpaper picker** (`SUPER + W`): a Material 3 carousel with a big sharp wallpaper in
  focus, narrower neighbours, search, All / Pictures / Live and shuffle. Settings can turn
  the shell's wallpapers or the picker off; slideshow and live wallpapers stay.
- **Window rules**: your own rules for any app (workspace, floating, size, every workspace,
  fullscreen, maximized, see-through) and a gaming workspace for Steam, Proton, Wine,
  gamescope and Minecraft. Your own Hyprland settings live in `~/.config/hypr/user.lua`,
  which no update touches.
- **Login screen**: the shell's own SDDM theme in Material 3, with your wallpaper, colors
  and picture, a big clock, blur and a rising login card. Settings can install or update it,
  make SDDM start at boot, or go back to SDDM's theme.
- **File manager picker** in Settings > Desktop > Look & Feel (Files, Thunar, Nemo, Dolphin,
  PCManFM), opened with `SUPER + E` and for every "open folder"; wallpaper colors reach GTK
  and KDE apps, and Files gets a Material 3 look, each with a switch.
- **Performance**: the bar's shadow no longer costs frames, Settings can wait ready in the
  background or start on demand, menus and panels are made only when opened, and the CPU,
  RAM and disk rings glide instead of blinking.
- **Languages**: the whole shell follows the 20 languages of Settings > System > Languages
  (bar, cards, control center, menus, notifications, launcher, clipboard, wallpaper picker,
  widgets and lock screen); Japanese, Korean and Chinese fonts are downloaded on demand.
- **Bar and desktop**: the bar on every screen, the date in the Dynamic island, one
  workspace color from the wallpaper, a transparent btop theme, a music card, dock icons in
  the wallpaper's colors, smoother Task view, a steadier Wi-Fi menu and better Bluetooth
  headphones.
- **Security and privacy**: third-party downloads are pinned and checked with SHA-256
  before unpacking, archives cannot write outside their folder, updates come only from this
  project and a changed installer asks first. The `input` group is opt-in, weather needs a
  place and uses HTTPS, lyrics are opt-in, and update checks run once a day.
- **Artix Linux** is supported (OpenRC, runit, s6 or dinit) with Arch's repositories,
  services through your init and a D-Bus login session; Flatpak works without systemd, and
  Fedora / Nobara install through COPR.
- **Installer**: long steps show their output as they run, `--no-upgrade` skips the system
  update, updates keep your edits, ZIP copies turn into git copies, update terminals no
  longer pile up, the keyboard layout survives updates, and a left-over pacman lock is
  reported before anything starts.
- **Kept from the shell's own fixes**: the bottom-right screen corner opens the control
  center, and the launcher answers at once without a double toggle.

## Platform support

This is a **Linux/Wayland** desktop shell built on Quickshell, Hyprland and niri. There is no
native macOS build.

## Upgrade

From v1.1:

```bash
git pull
./install.sh --update
```

Your settings and changed files are kept; the installer stores replaced files in
`~/.config/blvcksyxx-shell-backup-<time>/`. A fresh install is in the README.

- JSON validation for every JSON file
- `bash tests/security.sh`

## Verifying the download

Release tags and `SHA256SUMS` are signed with the project's SSH signing key
(`SHA256:n/ILvwETafTMBy9wi162zxGxu6TL8M9i+GJKC3zOd0o`). Download `SHA256SUMS`,
`SHA256SUMS.sig` and `trusted-signers` next to the archive, then:

```bash
ssh-keygen -Y verify -f trusted-signers -I blvcksyxx-release \
  -n blvcksyxx-release -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS
```

`install.sh --update` fetches the update, verifies that the exact commit is either a signed
release tag or a signed commit from the project key, and only then fast-forwards. More in
[SECURITY.md](https://github.com/blvcksyxx/blvcksyxx-shell/blob/main/SECURITY.md).
