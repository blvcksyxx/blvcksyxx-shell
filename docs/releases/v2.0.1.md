# blvcksyxx shell v2.0.1

v2.0.1 is a small patch for the version check. It fixes what the Update Center and
`rice-update check` showed on v2.0.0, and how they compare patch releases.

## What went wrong

The version comparison treated the part after the first dot as a decimal:
`2.0.0` became `0.0.0` and fell back to a hardcoded `2.01`. So the Update Center said
`blvcksyxx shell V2.01`, and a patch release such as `2.0.1` would not have been seen as
newer than `2.0.0`.

## What changed

- `rice-update check`, the Update Center and the update notification read
  `~/.config/rice/version` correctly: `2.0.0` is shown as V2.0.0
- Every part of a version is compared as a number:
  `2.0.0` equals `2.0`, `2.0.1` is older than `2.1`, and `2.10` is newer than `2.1`.
  A pre-release suffix (`-rc1`) is ignored
- A computer without a `VERSION` file is treated as older than every release (`0.0.0`),
  so it is offered the update instead of pretending to be 2.01
- Nothing else changes: settings, themes, wallpapers, the bar, live windows and your
  edits stay

## Checks run for this release

- version checks: `2.0.0` parses as V2.0.0, `2.0.1` is newer than `2.0.0`,
  `2.1` is newer than `2.0.1`, and `1.11.1` is newer than `1.11`
- `rice-update check` with a temporary home and the new helper: `installed` and `latest`
  both `2.0.1`, `update: false`
- `bash -n` over the installer and all shell helpers
- `python3 -m py_compile` over the installer tools and every Python helper
- `qmllint` over all QML files
- JSON validation for every JSON file
- `bash tests/security.sh` (`26 checks passed`)
- installer dry run on Linux (`--dry-run --yes --no-packages`)
- a live update with `./install.sh --update --yes --no-packages`; the Update Center then
  showed `blvcksyxx shell V2.0.1`

## Verifying the download

Release tags and `SHA256SUMS` are signed with the project's SSH signing key
(`SHA256:n/ILvwETafTMBy9wi162zxGxu6TL8M9i+GJKC3zOd0o`). Download `SHA256SUMS`,
`SHA256SUMS.sig` and `trusted-signers` next to the archive, then:

```bash
ssh-keygen -Y verify -f trusted-signers -I blvcksyxx-release \
  -n blvcksyxx-release -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS
```

Updating an installed copy:

```bash
./install.sh --update --yes
# or
rice-update
```
