# blvcksyxx shell v2.0.0

v2.0.0 brings the whole upstream V4.77–V4.83 update into blvcksyxx shell, with the fork's
branding, security and behaviour kept: the Edge bar, the Toolbox, screenshot
text / translation / colour picking, the record menu, the key sheet, your own themes, files
in the launcher and live wallpapers on the login screen.

Nothing is reset. Your settings, wallpapers and edits stay, and your live bar is kept. The
old Onyx launcher default moves to the Wallpaper look once, unless you chose Onyx yourself.

## Highlights

- **Edge bar.** A new bar style in Settings > Bar and the default for new installs. Every
  part is one piece with the screen edge, with its own Transparency and blur; **Frame along
  the edge** keeps only the pills. It follows the zones and the island in the same frame.
- **Toolbox on `SUPER + X`.** Tasks, a note, a focus timer, a converter (units and money),
  the system (processor, graphics, memory, disk, network, temperatures) and a chat, on a
  sheet at the screen edge. It opens like the control centre, has its own Settings page,
  transparency, blur and an optional island, and remembers the tab you used last.
- **Screenshots.** Read the text in a region (tesseract), translate it (translate-shell;
  Google's endpoint only when you press Translate), search with the picture, or pick the
  colour of a pixel. The result card keeps the text or colour on the clipboard.
- **Record menu on `SUPER + SHIFT + R`.** Region, window or screen, computer sound and
  microphone (both on by default), with a fallback that records without sound.
  `wf-recorder` and `ffmpeg` come from the installer; with `wf-recorder` the computer's
  sound is used, while `gpu-screen-recorder` can take both.
- **Key sheet on `SUPER + /`.** Every shell key in groups, with the keys you changed in
  Settings > Keybinds.
- **Your own themes.** Settings > Appearance > Themes saves the current colours, wallpaper,
  corners, shapes, bar, widgets, notifications, windows, motion and font under a name. They
  live in `~/.config/rice/themes/presets.json`, survive updates and are included in
  backups. Export and import are plain JSON.
- **Launcher.** Files and folders in your home appear after three letters (`/` in front
  shows only files), using `fd`, else `locate`, else a short walk; `.cache` and
  `node_modules` are left out. The new Wallpaper look tints the launcher with your
  wallpaper's colours and is the default for new installs.
- **Live wallpapers on the login screen.** The video plays on the SDDM login screen when
  SDDM's Qt has QtMultimedia; one frame of that video is the picture. Without it the picture
  stays.
- **Settings.** A new Toolbox page, Edge bar controls, frame along the edge, and the
  custom-theme controls; the bar and launcher previews follow the new defaults.

## Kept from the fork

- blvcksyxx branding throughout; upstream's names only remain in the MIT license and the
  historical changelog.
- The bottom-right control-centre corner.
- The fast launcher (`maxAge: 4000`).
- The matugen / terminal include naming and the wallpaper cache path.
- Signed-update verification and the SHA-256 pins.
- The local-only AI chat: Ollama at `http://localhost:11434` by default, no cloud or
  OpenAI-compatible provider, and no keys in the UI. `~/.config/rice/ai.json` is mode 0600.

## Installer and translations

- `tesseract` with the English and Russian language packs, `translate-shell`, `fd`
  and `plocate` are added for the new tools on Arch and Fedora; NixOS gets the same
  packages. `wf-recorder` and `ffmpeg` were already installed.
- Russian and English are complete for the new screens. Other languages fall back to
  English instead of showing empty labels.

## Upgrade

From any 1.x release, in the repository:

```bash
git pull
./install.sh --update
```

The updater verifies the signed tag before it fast-forwards, keeps your edited files, and
backs up everything it replaces. The old Onyx launcher default becomes the Wallpaper look
once, unless you chose Onyx yourself; your live bar stays as it is, and Edge applies to
fresh installs.

A fresh install is in the [README](https://github.com/blvcksyxx/blvcksyxx-shell#install-in-one-minute).

## Verifying the download

Release tags and `SHA256SUMS` are signed with the project's SSH signing key
(`SHA256:n/ILvwETafTMBy9wi162zxGxu6TL8M9i+GJKC3zOd0o`). Download `SHA256SUMS`,
`SHA256SUMS.sig` and `trusted-signers` next to the archive, then:

```bash
ssh-keygen -Y verify -f trusted-signers -I blvcksyxx-release \
  -n blvcksyxx-release -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS
```

`install.sh --update` fetches the update, verifies that the exact commit is either a signed
release tag or a signed commit from the project key, and only then fast-forwards. More in
[SECURITY.md](https://github.com/blvcksyxx/blvcksyxx-shell/blob/main/SECURITY.md).
