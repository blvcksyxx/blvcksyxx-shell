# blvcksyxx shell v2.1.0

v2.1.0 brings the whole upstream V4.84 update into blvcksyxx shell, and adds the next set
of desktop features: a game library, a privacy panel, local text work on top of the
Ollama chat, Markdown notes and a clipboard widget. The fork's branding, fast launcher,
bottom-right control-centre corner, signed updates and SHA-256 pins stay.

Nothing is reset. Your settings, wallpapers, themes and edits stay. Settings is lazy by
default now (it quits a minute after you close it); **Settings > Desktop > Performance >
Keep Settings ready** brings back the old behaviour.

## Highlights

- **Much lighter.** The task view lets its window pictures go when it is closed, waves are
  drawn about 30 times a second instead of once per screen frame, the Infinite Desktop
  wallpaper exists only while Infinite Desktop is on, the launcher is made on first use
  and let go after 10 minutes, and the shell wakes up less often. `rice-perf` shows what
  each part uses right now.
- **Minimize and stack windows.** `SUPER + H` minimizes, `SUPER + SHIFT + H` brings the
  last one back, `SUPER + T` starts or leaves a stack (tabs), `SUPER + CTRL + Right/Left`
  walks the stack, and `SUPER + CTRL + SHIFT + Left/Right` puts a window into it. All of
  them can get other keys in Settings > System > Keybinds.
- **Your own keys.** Settings > System > Keybinds > "Turn a key off" takes any window
  manager key away, and the ready-made actions (minimize, restore, fullscreen, close,
  float, pin, screenshot ...) can be given to keys of your own.
- **Launcher favourites.** Right-click an app (or `Ctrl + D`) and it goes first, with a
  star.
- **Volume.** Sliders, keys and the bar's wheel use a gentler curve, and the top goes to
  150 % on this fork. Low volumes and the loudest level are set in Settings > Sound.
- **Login screen clocks.** Classic, stacked, center, pill and shapes in Settings >
  Desktop > Idle & Lockscreen > Login screen (`rice-sddm clock STYLE`). Classic is the
  default here.
- **Games in the Toolbox.** `SUPER + X` > Games lists Steam, Lutris and menu games, with
  search, refresh and one click to launch (`rice-games`). It works with an empty library
  too and says what to install.
- **Local text work.** Toolbox > Auto summarizes, translates English/Russian, extracts
  facts or makes tasks with the local Ollama model. `rice-tools ai auto ...` does the
  same in a terminal; nothing leaves the computer. OCR reads `eng` and `rus` when
  `tesseract` is installed.
- **Notes ask your files.** Toolbox > Chat has a Files toggle: index Documents, Notes,
  Desktop and the Note widget once, then answers cite the files they came from.
  `rice-tools ai index|docs|forget|ask` is the terminal side.
- **Markdown in Toolbox > Note.** Edit and Preview, H1/H2, bold, italic, list, to-do,
  quote, code and link buttons, and `Ctrl + P` to switch. The same note as the desktop
  widget, saved as you type.
- **Clipboard widget.** A desktop widget with the newest things you copied, pins first;
  click one to put it back. The full history stays on `SUPER + V` (`rice-clip`, cliphist).
- **Privacy.** Settings > Security now has the devices in use (microphone, camera,
  screen), a lock-now button with the autolock time, clipboard history and clear, private
  DNS presets, a firewall switch and the broad permissions of installed Flatpak apps
  (`rice-security privacy`). Nothing is stored or sent anywhere.
- **Custom key colour.** Settings > Appearance > Colors takes any `#RRGGBB` colour and
  makes the whole shell from it (`rice-colors custom #8B7BFF`).
- **Themes.** The theme editor from v2.0 stays: save the current look under a name, export
  and import it, and keep your themes in `~/.config/rice/themes`.

## Kept from the fork

- blvcksyxx branding throughout; upstream's names remain only in the MIT license and the
  historical changelog.
- The bottom-right control-centre corner.
- The fast launcher (`maxAge: 4000`).
- The `rice-*` naming, matugen / terminal includes and the wallpaper cache path.
- Signed-update verification and the SHA-256 pins.
- Local Ollama only: `http://localhost:11434`, no cloud or OpenAI-style provider in the
  UI, no API keys. `~/.config/rice/ai.json` is readable only by you.
- Volume tops out at 150 %.

## Installer and translations

- `cliphist` and `wl-clipboard` are part of the tool package on Arch and Fedora (they were
  already); the clipboard history and the widget use them.
- `tesseract` with English and Russian language data, `fd` and `plocate` are still the
  optional packages for OCR and file search.
- Russian and English are complete for the new screens; other languages fall back to
  English instead of showing empty labels.

## Upgrade

From any 2.0 release, in the repository:

```bash
git pull
./install.sh --update
```

The updater verifies the signed tag before it fast-forwards, keeps your edited files, and
backs up everything it replaces. A fresh install is in the
[README](https://github.com/blvcksyxx/blvcksyxx-shell#install-in-one-minute).

## Verifying the download

Release tags and `SHA256SUMS` are signed with the project's SSH signing key
(`SHA256:n/ILvwETafTMBy9wi162zxGxu6TL8M9i+GJKC3zOd0o`). Download `SHA256SUMS`,
`SHA256SUMS.sig` and `trusted-signers` next to the archive, then:

```bash
ssh-keygen -Y verify -f trusted-signers -I blvcksyxx-release \
  -n blvcksyxx-release -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS
```

`install.sh --update` fetches the update, verifies that the exact commit is either a signed
release tag or a signed commit from the project key, and only then fast-forwards. More in
[SECURITY.md](https://github.com/blvcksyxx/blvcksyxx-shell/blob/main/SECURITY.md).
