# blvcksyxx shell v2.1.1

v2.1.1 is a small follow-up to v2.1.0: the Toolbox now also opens from the top-right
screen corner. Move the pointer into the top-right corner for a moment and the sheet
slides in, the same as `SUPER + X`. Move away and it stays; close it with `Esc` or a
click outside.

Nothing else changes. Your settings, wallpapers, themes and edits stay.

## Highlights

- **Toolbox from the top-right corner.** A small overlay sits in the top-right corner;
  hover it briefly and the Toolbox opens on the right edge. It does not take the pointer
  from windows that sit under it, so normal work is not affected. The same trigger as
  `SUPER + X`, so the tab, width, transparency and blur you set in Settings > Desktop >
  Toolbox still apply.

## Kept from v2.1.0

- The whole upstream V4.84 update and the 2.1 features: minimize and stack windows, your
  own keys, launcher favourites, a gentler volume, login screen clocks, niri monitor
  scrolling, the game library, local text work, Markdown notes, the clipboard widget, the
  privacy panel, a custom key colour and local RAG over your notes.

## Upgrade

From any 2.1 release, in the repository:

```bash
git pull
./install.sh --update
```

The updater verifies the signed tag before it fast-forwards, keeps your edited files, and
backs up everything it replaces. A fresh install is in the
[README](https://github.com/blvcksyxx/blvcksyxx-shell#install-in-one-minute).

## Checks run for this release

- `bash -n` over the installer and all shell helpers
- `python3 -m py_compile` over the changed helpers
- `qmllint` over every changed QML file, including the new top-right corner trigger
- JSON validation for every JSON file
- `bash tests/security.sh`
- installer dry run on Linux (`--dry-run --yes --no-packages`)
- a live install of v2.1.1 and a smoke test of the desktop and the Toolbox corner trigger

## Verifying the download

Release tags and `SHA256SUMS` are signed with the project's SSH signing key
(`SHA256:n/ILvwETafTMBy9wi162zxGxu6TL8M9i+GJKC3zOd0o`). Download `SHA256SUMS`,
`SHA256SUMS.sig` and `trusted-signers` next to the archive, then:

```bash
ssh-keygen -Y verify -f trusted-signers -I blvcksyxx-release \\
  -n blvcksyxx-release -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS
```

`install.sh --update` fetches the update, verifies that the exact commit is either a signed
release tag or a signed commit from the project key, and only then fast-forwards. More in
[SECURITY.md](https://github.com/blvcksyxx/blvcksyxx-shell/blob/main/SECURITY.md).
