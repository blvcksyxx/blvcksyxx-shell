# blvcksyxx shell v1.1

v1.1 adds the Task view, bar cards, new widgets, whole-look themes and a safer Update Center.
The release includes the blvcksyxx identity, crescent-moon artwork, extra configuration and
custom Hyprland binds.

## Highlights

- **Task view** (`SUPER + Tab`) and **window switcher** (`ALT + Tab`) on Hyprland and niri.
  niri's overview moves to `SUPER + O`; its own switcher is turned off.
- **Settings > Keybinds** keeps the shell's keys and your own keybinds on one page, with new
  keys for the Task view and the switcher.
- **Bar cards**: Weather, System and Date modules grow out of their pill into Material 3
  cards. The bar can stand on the top, bottom, left or right edge.
- **New widgets**: Forecast, Music card and Date & time (the System widget became a bar card).
  One Material You card style, a frame-rate choice for moving parts and automatic hiding while
  windows are open.
- **Wallpapers and desktop menu**: animations, slideshow, live wallpapers, space wallpapers
  and the Material 3 right-click desktop menu.
- **Whole-look themes**: blvcksyxx, Terminal, Glass, Neon, Ember and Frost, plus colors in
  VSCodium / VS Code and Discord.
- **Update Center**: when `git pull` cannot run, local changes are kept on a branch and in
  a stash while the update goes through.
- **Security** stays in Settings: ClamAV scans, quarantine, system check, shell-file watch
  and the installer baseline step.
- **Installer platform gate**: Linux with Hyprland 0.55+ or niri 25.05+ is supported.
  macOS is rejected with a clear message before anything is changed.

## Platform support

This is a **Linux/Wayland** desktop shell built on Quickshell, Hyprland and niri. There is no
native macOS build; a macOS version would have to be a separate native application.

## Upgrade

From v1:

```bash
git pull
./install.sh --update
```

Your settings and changed files are kept; the installer stores replaced files in
`~/.config/blvcksyxx-shell-backup-<time>/`. A fresh install is in the README.

## Checks run for this release

- `bash -n` over the installer and all shell helpers
- `python3 -m py_compile` over the installer tools
- `qmllint` over all QML files (no syntax errors)
- JSON validation for every JSON file
- installer dry run on Linux (`--dry-run --yes --no-packages`)
- platform gate on a simulated Darwin system (exit 1, clear message)
- Quickshell runtime load of Settings (pages 2, 3, 29, 30, 32, 33, 34, 35), Welcome,
  Desktop and the Wallpaper tab
- read-only checks of `rice-theme`, `rice-bar`, `desktop-set`, `rice-security`, `rice-stats`
  and `rice-update --offline`

## Verifying the download

Release tags and `SHA256SUMS` are signed with the project's SSH signing key
(`SHA256:n/ILvwETafTMBy9wi162zxGxu6TL8M9i+GJKC3zOd0o`). Download `SHA256SUMS`,
`SHA256SUMS.sig` and `trusted-signers` next to the archive, then:

```bash
ssh-keygen -Y verify -f trusted-signers -I blvcksyxx-release \
  -n blvcksyxx-release -s SHA256SUMS.sig < SHA256SUMS
sha256sum -c SHA256SUMS
```

`./install.sh --update` verifies the fetched commit or release tag before it runs. More in
[SECURITY.md](https://github.com/blvcksyxx/blvcksyxx-shell/blob/main/SECURITY.md).
